# worship-edit

주일 예배 찬양 실황 멀티캠 영상을 **Final Cut Pro XML**로 받아
규칙에 따라 앵글 컷을 나누고, 악보 가사를 목소리에 맞춰 자막 타이틀로 넣은 XML을 만듭니다.

## 진행 단계
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 엔진 + 명령어 버전 (구조 분석, 목소리 분리, 규칙 컷, 가사 싱크, 타이틀) | ✅ |
| 2 | 앱 안에서 Whisper 받아쓰기 + 가사 자동 정렬 | 예정 |
| 3 | 가사 보관함 (곡 제목별 가사·진행 순서 저장) | 예정 |
| 4 | Mac 앱 화면 (끌어다 놓기, 역할 확인, 검토 타임라인) + GitHub 자동 빌드 | 예정 |
| 5 | 학습 루프 (다듬은 최종본과 비교해 규칙값 갱신) | 예정 |

## 준비물 (파이널 컷)
1. 컷하지 않은 멀티캠 클립 하나가 올라간 프로젝트 → 파일 → XML 내보내기 (1.14, `.fcpxmld`)
2. 같은 프로젝트 오디오 → **⌥X로 선택 구간 해제** → 공유 → 파일 내보내기 → 오디오만

## 명령어 (1단계)
```bash
pip install -e .
worship-edit check  프로젝트.fcpxmld 오디오.mp3          # 길이·앵글 역할 확인
worship-edit separate 오디오.mp3 목소리.wav               # 목소리 분리 (모델 자동 다운로드)
worship-edit analyze 오디오.mp3                           # 곡·멘트 구조 추정
worship-edit build 프로젝트.fcpxmld 오디오.mp3 --vocals 목소리.wav --lyrics 가사.txt -o 결과.fcpxml
```
`가사.txt`: 한 줄에 `시간|가사[|C]` (C = 후렴 블록 첫 줄). 2단계에서 자동 생성으로 바뀝니다.

## 컷 규칙
1. 같은 앵글 연속 금지 · 2. 인도자 노래 구간 35% · 3. 조용한 구간 드럼 금지
4. 곡 시작: 드럼 카운트 → 드럼, 건반 인트로 → 피아노 · 5. 드럼 예비박 뒤 첫 간주 → 기타
A. 멘트·기도 인도자 고정 · B. 후렴 첫 소절 인도자/싱어 · C. 마지막 후렴 컷 20% 짧게 · D. 곡 끝 8초 인도자

## 자막 스타일
Basic Title · NanumMyeongjo 50 · Position 0 -450 · Outline 검정 20% / 0.5 · Drop Shadow 검정 75% / Blur 7.53 / Distance 5 / 315°

## 앵글 역할 자동 분류
`C9xxx` 인도자 · `C1xxx~C8xxx` 싱어 · `DJI` 두 대 중 번호가 작은 쪽 드럼, 큰 쪽 피아노 · `GHxx` 기타 · `YYYY-MM-DD HH-MM-SS` 실황 녹화본(오디오)
